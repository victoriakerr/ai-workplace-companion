# AI-Workplace-Companion
 
## Overview
A responsive AI-powered dashboard to automate emails, meeting notes, and task planning.
Built with Lovable for ASA 14 - AI Skills Acceleration, Cape Town.
 
## Features
1. **Smart Email Generator** - Formal, Friendly, Persuasive tones
2. **Meeting Notes Summarizer** - Summary, Action Items, Decisions
3. **AI Task Planner** - Prioritize and schedule daily tasks
 
## Prompt Engineering
We used the RTCF framework: Role, Task, Context, Format.
